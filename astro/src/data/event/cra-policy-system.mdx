The event will start with a ~25 min presentation and demo of the Free and opens Source _Policy System_.

You use it as an AI Extension (skill) it knows all the regulatory rule sets you feed to it: CRA, NIS2, GDPR, EU AI Act, etc. You can even feed it your own internal "How We Work" rule book.

You can then query it any compliance questions you have — about your own code base, roles, processes, or even about your suppliers. It will give you a clear answer and a reference to the combined rule set it used to answer your question.

:::note
This event is the third event in a series of three about the CRA, it's consequences on the software development industry, including the development and usage of Free Open Source Software (FOSS).
:::
