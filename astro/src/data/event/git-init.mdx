As a distributed version control system, Git is our GOAT, but its freedom allows a variety of workflows.

Merge or rebase? Hooks or aliases? Trunk or GitFlow? SemVer or GitDate? Remotes or Submodules? CODEOWNERS or RESPONSIBILITIES?

We will set up bare repositories and incrementally push changes to it documenting our decisions, which will serve as basis for our future projects.

This will set us up to start innovating on the Web from next time!
