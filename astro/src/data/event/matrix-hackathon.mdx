[New to Matrix?](/writings/new-to-matrix) 👈 Learn more!

An online hackathon. The goal is to gain experience with hosting various matrix servers (synapse, dimension, mxisd, etc.).

- Find a suitable helm chart for a matrix server and deploy it in a Kubernetes cluster
- Find a suitable docker image for a matrix server and deploy it in a docker cluster of your choice
- Find a terraform module for a matrix server and deploy it in a cloud provider of your choice
- Bring an old PC and install it on bare metal

There are no rules, anything goes. The goal is simply to explore and gain experience with hosting various matrix servers.

Even if you aren't an IaC saavy developer you can still join and ask all the questions you want. We will have a few IaC experts on hand to help you out.
