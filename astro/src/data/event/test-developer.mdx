What happens when a Test Manager stops just talking about software quality and starts building software?

Join us for a live demo of an AI-assisted Test Case Generator, followed by an open discussion about how QA professionals can become hands-on creators through Vibe Coding and Citizen Development.

## What we’ll explore

- **AI-assisted test case generation** — generating test cases from requirements without writing code.
- **Product criticality and risk** — incorporating risk, product criticality and ISTQB-aligned test design into generated test cases.
- **Vibe Coding and Citizen Development** — exploring how QA professionals can move from using software to building their own tools with AI.

## Format

A short introduction, live demo and facilitated discussion, with room for questions, feedback and shared learning.

The session is intended to be interactive, encouraging participants to exchange experiences, challenge ideas and explore new possibilities together.

No coding experience required — just curiosity!

## Who should join?

Test Managers, QA professionals, testers, developers and anyone interested in AI-assisted software development.

Let’s explore, learn and build together!
